X-Bot Lib

Integre seus projetos MQL4 e MQL5 ao X-Bot utilizando uma biblioteca simples para envio e recebimento de sinais.

Integração simples

A X-Bot Lib permite integrar seu projeto MetaTrader ao X-Bot sem a necessidade de implementar toda a comunicação diretamente no seu Expert Advisor ou indicador.

Funções disponíveis

SendSignal()
Envia um sinal para o X-Bot.
ReceiveSignal()
Recebe um sinal enviado pelo X-Bot.

Versões

MetaTrader 4

Biblioteca para projetos desenvolvidos em MQL4.

X-Bot Lib.ex4
MetaTrader 5

Biblioteca para projetos desenvolvidos em MQL5.

X-Bot Lib.ex5

Instalação

A instalação consiste em copiar a biblioteca correspondente para a pasta Libraries da instalação do MetaTrader.

MetaTrader 4

Utilize o arquivo:

Arquivo 
X-Bot Lib.ex4

Coloque o arquivo dentro da pasta:

Estrutura 
MQL4
└── Libraries
    └── X-Bot Lib.ex4

MetaTrader 5

Utilize o arquivo:

Arquivo 
X-Bot Lib.ex5

Coloque o arquivo dentro da pasta:

Estrutura 
MQL5
└── Libraries
    └── X-Bot Lib.ex5
Após a instalação

Depois de copiar o arquivo para a pasta correspondente, a biblioteca estará disponível para utilização no seu projeto.

SendSignal()

Use SendSignal() para enviar um sinal para o X-Bot.

Assinatura

MQL 
bool SendSignal(
    string symbol,
    string direction,
    int duration,
    string strategy
);

Parâmetros

Parâmetro Tipo Descrição
symbol string Ativo relacionado ao sinal.
direction string Direção do sinal.
duration int Duração do sinal em segundos.
strategy string Nome utilizado para identificar a origem do sinal.

symbol

Ativo relacionado ao sinal.

Exemplos 
EURUSD
GBPUSD
USDJPY

direction

Direção do sinal.

Utilize:

Valores 
CALL
PUT

duration

Duração do sinal em segundos.

Exemplo 
60

O valor acima representa 60 segundos.

strategy

Nome utilizado para identificar a origem do sinal. Você pode utilizar qualquer nome definido pelo seu projeto.

Exemplos 
my_strategy
strategy_01
custom_strategy
signal_system

Retorno

A função retorna true quando o envio é realizado com sucesso.

Em caso de falha, retorna false.

Exemplo

MQL 
bool result = SendSignal(
    "EURUSD",
    "CALL",
    60,
    "my_strategy"
);

if(result)
{
    Print("Sinal enviado com sucesso.");
}
else
{
    Print("Não foi possível enviar o sinal.");
}

ReceiveSignal()

Use ReceiveSignal() para receber um sinal enviado pelo X-Bot.

Assinatura

MQL 
string ReceiveSignal(int timeout);

timeout

Define por quanto tempo a função poderá aguardar por um sinal.

O valor é informado em milissegundos.

Exemplo

MQL 
string signal = ReceiveSignal(5000);

Nesse exemplo, a função poderá aguardar até 5 segundos.

Valor retornado

Quando um sinal é recebido, o resultado possui quatro valores separados por vírgula.

Formato 
EURUSD,CALL,60,my_strategy

A ordem dos valores é:

  1. Symbol
  2. Direction
  3. Duration
  4. Strategy

Quando nenhum sinal é recebido

Se nenhum sinal for recebido dentro do período informado, a função retorna uma string vazia.

MQL 
string signal = ReceiveSignal(1000);

if(signal == "")
{
    Print("Nenhum sinal recebido.");
}

MQL4

Utilize X-Bot Lib.ex4 com projetos desenvolvidos em MQL4.

Enviar sinal

MQL4 
bool result = SendSignal(
    Symbol(),
    "CALL",
    60,
    "my_strategy"
);

if(result)
{
    Print("Sinal enviado.");
}

Receber sinal

MQL4 
string signal = ReceiveSignal(100);

if(signal != "")
{
    Print(
        "Sinal recebido: ",
        signal
    );
}

Exemplo de resultado

Resultado 
EURUSD,CALL,60,my_strategy

O texto recebido pode ser separado e utilizado pelo seu projeto conforme a necessidade.

Exemplo completo

O exemplo abaixo utiliza as duas funções da X-Bot Lib.

MQL4

MQL4 
bool SendMySignal()
{
    return SendSignal(
        Symbol(),
        "CALL",
        60,
        "my_strategy"
    );
}

void CheckSignal()
{
    string signal =
        ReceiveSignal(100);

    if(signal == "")
        return;

    Print(
        "Novo sinal: ",
        signal
    );
}

MQL5

MQL5 
bool SendMySignal()
{
    return SendSignal(
        _Symbol,
        "CALL",
        60,
        "my_strategy"
    );
}

void CheckSignal()
{
    string signal =
        ReceiveSignal(100);

    if(signal == "")
        return;

    Print(
        "Novo sinal: ",
        signal
    );
}

Exemplo recebido

Sinal 
EURUSD,PUT,60,my_strategy

Os dados correspondem a:

Estrutura 
Symbol    = EURUSD
Direction = PUT
Duration  = 60
Strategy  = my_strategy

Boas práticas

Envie somente novos sinais

Chame SendSignal() quando um novo sinal for identificado.

Verifique o resultado do envio

MQL 
if(SendSignal(
    "EURUSD",
    "CALL",
    60,
    "my_strategy"
))
{
    Print("Sinal enviado.");
}
else
{
    Print("Falha no envio.");
}

Verifique o resultado de ReceiveSignal()

MQL 
string signal =
    ReceiveSignal(100);

if(signal == "")
    return;

// Processar sinal

Valores

Formato

Exemplo
